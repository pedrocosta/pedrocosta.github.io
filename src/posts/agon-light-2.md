# THE AGON LIGHT 2

The Agon Light 2 is a fascinating machine.

It looks and feels like an 8-bit computer,
but uses modern hardware underneath.

That combination makes it particularly interesting.

## The idea

A modern microcontroller drives the video,
while the system provides an environment
that feels much closer to classic home computers.

Why it matters
There is something liberating about working
within a deliberately constrained environment.

You have to think about:

memory
graphics
input
performance
machine code
And that makes the computer feel tangible again.
