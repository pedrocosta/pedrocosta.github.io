# OLIMEX RVPC

RISC-V is particularly interesting because
it brings an open instruction set architecture
to the hobbyist world.

The Olimex RVPC is one of the machines
I have been experimenting with.

## Why RISC-V?

Open architectures are exciting.

Instead of treating the CPU as a black box,
you can actually learn how the instruction set works.

```text
LOAD
STORE
ADD
SUB
JUMP
BRANCH

The instruction set is small enough
to be understandable.

That is exactly the kind of computer
I enjoy exploring.

Next experiment
The next step is to write a tiny assembly program
and make it talk directly to the hardware.

No operating system.

Just CPU → memory → hardware.

That's where things get interesting.
